### Version 0.1.0 — October 13, 2026

- **The version number starts over at 0.1.0.** This is the first public release of the POS. It carries on from version 1.15.1 with the same features and the same data; only the number is new, so Help now shows 0.1.0.
- **Pickup tickets stay at $0.** When a customer picks up a gun that was paid for on its counter order, the ticket opens at $0 and stays there. The register no longer shows the list price or asks for a card, and you can only hand over what the order sold. If you see a price on a pickup ticket, take no payment and reload the page.
- **Everything else at the counter works as before.**
