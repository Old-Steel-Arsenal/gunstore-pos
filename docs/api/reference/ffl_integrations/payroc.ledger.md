## `payroc_transactions`

`POST /api/method/ffl_integrations.payroc.ledger.payroc_transactions`

**Auth (derived from code):** Roles: System Manager / Accounts Manager / Accounts User

Every Payroc gateway transaction from `from_date` to `to_date` (inclusive,

store time zone, at most 31 days), matched to the POS. Read-only.

| arg | type | required | default | description |
|---|---|---|---|---|
| `from_date` | string | yes | — | First day, YYYY-MM-DD. |
| `to_date` | string | yes | — | Last day, YYYY-MM-DD. |

**Returns:** {from_date, to_date, timezone, truncated, summary, transactions: [row], pos_only: [row]} — a transaction row is {date_time, type, status, batch_status, amount, reference, order_id, card, customer_name, terminal, source (counter | web | virtual terminal | ""), pos_doctype, pos_name, pos_amount, pos_refunded, flags: [str]}; pos_only rows are POS captures the search did not return, with the gateway's own status read back (skipped when truncated — the missing days would all land there).
