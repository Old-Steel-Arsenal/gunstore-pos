**Auth (derived from code):** Roles: Stock Manager / System Manager

List one Item on GunBroker as a quantity listing.

Ammunition, optics, parts — one listing standing for the stock on hand — and a
uniform-price firearm, listed as a MODEL: one listing standing for the guns that
are free to sell, filed under the bare item code with the licence requirement on.
A gun priced one by one is refused here; those are listed one at a time from the
Serial No form.

| arg | type | required | default | description |
|---|---|---|---|---|
| `item_code` | string | yes | — | The Item to list. |
| `relist` | int | str | no | `0` | Pass 1 when the operator is deliberately re-listing something that was ended by hand. It lifts that one sentinel and nothing else. |
| `ship_cost` | float | str | no | `None` | The buyer-paid shipping rate for this listing, saved on the Item before it is listed. Omit to keep what is there; 0 clears it, so the default in GunBroker Settings applies (the long gun / handgun one for a model, the accessory / ammo one otherwise). |
| `listing` | dict | str | no | `None` | For a model only, the terms chosen in the Send dialog, as JSON: {"type": "Fixed Price", "premium": {"featured": 0, "showcase": 0, "sponsored_onsite": 0, "view_counter": 0}}. "premium" is GunBroker's paid promotions (extra fees, one per ticked flag): they can only be bought here, when the listing is created, never added to a live one, and a re-listing the system does by itself after a sell-out never buys them. A "premium" object replaces all four flags (omitted names count as off); omit the key to keep the recorded ones; an unknown name is refused.
