provider's health line instead of blanking the page.

**Returns:** {distributors: [per-house rows with flags/priority/health and summary: [{label, value, tab}]], providers: [{code, settings_doctype, used_by}], can_write, catalog_local: {local, worker_running, warning}, can_sync_now (Local catalog and System Manager), capabilities: {catalog} (the data_service capability the page shows)}, and per row catalog_lanes (Local catalog only, else null): {lanes: [{lane, last_success_at, rows, last_status, error_class}], offers_total, offers_active}.
