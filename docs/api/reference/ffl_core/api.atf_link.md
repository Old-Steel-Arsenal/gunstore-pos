## `create_party_from_atf`

`POST /api/method/ffl_core.api.atf_link.create_party_from_atf`

**Auth (derived from code):** Roles: Sales User / Purchase User / Stock Manager / System Manager

Create a dealer Customer/Supplier from an ATF FFL Record (idempotent).

Sets is_ffl_dealer and the atf_ffl_record link; the party's validate
hook then fills the license fields from the record. If a party already
carries the record's FFL number it is returned as-is (the link is
healed if missing) — never duplicated or renamed.

| arg | type | required | default | description |
|---|---|---|---|---|
| `record` | string | yes | — | ATF FFL Record name (the directory row to build from). |
| `party_type` | string | yes | — | "Customer" or "Supplier". |

**Returns:** {"name": <party name>, "created": bool} — created=False when an existing party with this FFL number was reused.

**Permissions:** Sales User / Purchase User / Stock Manager / System Manager.
