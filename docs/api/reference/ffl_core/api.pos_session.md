**Auth (derived from code):** Any authenticated user — no explicit role gate at function entry (deliberate open reads document this in Permissions).

Resolve the POS opening entry for a shared register (override).

Replaces ERPNext's point_of_sale.check_opening_entry (wired via
override_whitelisted_methods): keeps the native behavior when the user
has their own open entry, and otherwise falls back to ANY open entry —
one register, one shift, many clerks (see module docstring for the
deadlock this solves).

**Permissions:** Open by design (endpoint-gates adjudication group A): ERPNext's own check_opening_entry is gateless, and this override must keep upstream's semantics — any clerk resuming the shared register calls it before a shift/role context exists.
